# Sectoral hints — common SOPs by sector

Used by Phase B (Mode 1) to seed the initial backlog. The skill picks the entry whose key
best matches `state.business.sector`. If nothing matches, fall back to **General services**.

Each suggestion below is a starting point. The user is expected to confirm, remove, or
extend the list before the backlog is persisted.

`area` and `name` shown below are the human-facing labels. When persisting via `add-pop`,
convert area to ALL-CAPS English (snake_case for multi-word) and name to English kebab-case.

---

## Aesthetic clinic / beauty salon

**Front-of-house**
- Opening procedure
- Client check-in
- Phone and message scheduling
- Closing procedure

**Service delivery**
- Skin cleansing
- Hair removal
- Nail service
- Hair coloring

**Operations**
- Instrument sterilization
- Inventory restock
- Biological waste disposal
- Incident handling (allergic reaction, complaint)

---

## Medical / dental clinic

**Front-of-house**
- Patient intake and registration
- Insurance verification
- Appointment confirmation calls

**Clinical**
- Vitals collection
- Standard exam protocol
- Prescription dispensing
- Post-procedure care instructions

**Operations**
- Sterilization and infection control
- Medical records archival
- Emergency response (cardiac, allergic)
- Biohazard waste disposal

---

## Restaurant / café

**Front-of-house**
- Opening checklist
- Greeting and seating
- Order taking and entry
- Closing and cash reconciliation

**Kitchen**
- Mise en place
- Prep and storage rotation (FIFO)
- Cooking line handoff
- Allergen handling

**Operations**
- Daily cleaning
- Supplier delivery receipt
- Food safety incident
- Refrigeration temperature log

---

## Retail / small shop

**Front-of-house**
- Opening and closing
- Customer greeting
- Sale and POS transaction
- Returns and exchanges

**Inventory**
- Receiving stock
- Shelf restock
- Stocktake (cycle count)
- Loss / theft incident

---

## E-commerce / DTC

**Order operations**
- Order intake validation
- Pick and pack
- Shipment label and dispatch
- Returns processing

**Customer support**
- Pre-sale inquiry
- Order status request
- Refund authorization
- Negative review response

**Marketing**
- Campaign launch checklist
- Newsletter scheduling
- Influencer onboarding

---

## Professional services office (law / consulting / accounting)

**Client lifecycle**
- New client intake and conflict check
- Engagement letter issuance
- Matter / project kickoff
- Closing and archival

**Delivery**
- Internal review and sign-off
- Deliverable handoff
- Client meeting preparation
- Time tracking and billing

---

## SaaS / software product

**Product**
- Feature request triage
- Bug report handling
- Release readiness checklist
- Incident postmortem

**Customer**
- Onboarding session
- Subscription cancellation
- Upgrade / downgrade
- Churn save attempt

**Operations**
- On-call rotation handoff
- Backup verification
- Access provisioning / revocation

---

## Education / tutoring

**Front-of-house**
- Student enrollment
- Payment and renewal
- Class scheduling

**Delivery**
- Lesson preparation
- Class delivery checklist
- Student progress tracking
- Parent / sponsor reporting

---

## Personal training / fitness studio

**Front-of-house**
- Trial class booking
- Membership signup
- Class check-in
- Cancellation and refund

**Delivery**
- Initial assessment
- Workout plan delivery
- Equipment cleaning between sessions
- Injury / incident response

- First contact and qualification

- Follow-up and feedback collection

**Operations**
